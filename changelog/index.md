## 版本历史

### v1.0.0 — 首次公测

Anotheru 首个公测版本，核心功能上线。

#### Au 触摸条

屏幕边缘一划即出的快捷操作面板。

支持 **20+ 快捷操作项**，按类别划分：

- **手机系统**：通知栏 / 锁屏 / 多任务 / 截图 / 返回 / 回到桌面 / WiFi / 关机/重启 / 控制中心 / 闪光灯 / 静音 / 音量加 / 音量减
- **音乐控制**：上一首 / 下一首 / 播放暂停
- **扫码**：微信扫码 / 支付宝扫码 / 支付宝付款码
- **Au 功能**：一键开关 VPN / 备份

#### 单指模式

可能是最好用的单手模式？大屏手机也能一只手搞定。

- 本地导出 / 导入备份文件
- 自动微信收藏备份
