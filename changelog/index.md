# 更新日志

AnotherU 各版本更新记录。下载安装包请前往 [下载页](/download/)。

## 版本历史

### v1.0.0 — 首次公测

AnotherU 首个公测版本，核心功能上线。

#### Au 触摸条

屏幕边缘一划即出的快捷操作面板。

- 支持 **20+ 快捷操作项**：通知栏 / 锁屏 / 多任务 / 截图 / 返回 / 回到桌面 / WiFi / 电源菜单 / 快捷设置 / 闪光灯 / 静音 / 音量加减 / 微信扫码 /
  支付宝扫码 / 付款码 / 上一首 / 下一首 / 播放暂停 / VPN 影子开关 / 备份
- 面板 Grid 自由配置，长按拖动排序
- 触发区域可调：位置 / 宽度 / 高度 / 边距（曲面屏防误触）
- 触摸区域透明度可调
- 上滑 / 下滑手势可绑定快捷操作
- 点按模式（防误触时可切换）

#### 单指模式

屏幕左右两侧的单手操作区域，大屏手机也能一只手搞定。

- 左 / 右区域独立配置
- 侧滑或点击均可触发
- 部分能力为会员专享

#### 数据备份与恢复

- 本地导出 / 导入备份文件
- 微信分享备份（发到「文件传输助手」，换机随时取回）

#### 账号与会员

- 手机号一键登录（验证码 + 密码双模式），首次登录自动注册
- 会员充值页（星空背景 + 套餐选择 + 支付）

#### 设置与辅助

- 设置中心：权限管理 / 面板设置 / 数据备份入口
- 自动复制短信验证码（所有用户可用）
- 振动反馈开关
- 异常处理：日志导出 / 重启服务

#### 其他

- 保活服务：前台通知常驻，保障触摸条 & 无障碍服务持续运行
- 强制更新：自动检测新版本并提示升级
