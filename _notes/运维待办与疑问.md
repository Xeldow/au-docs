## 1. 后续如何更新站点

**站点源目录**：`F:\Xad\Wok\WorkSapce\AuOS\au-docs`（独立仓库 `github.com/Xeldow/au-docs`，与主项目 AnotherU 分离）。

**更新流程**：

1. 改内容：新增说明书在 `guide/` 加 `.md`，并到 `.vitepress/config.ts` 的 `sidebar` 补一条；`guide/index.md` 功能列表也补一行。
2. 本地预览（可选）：`npm run docs:dev`（首次先 `npm install`）。
3. 推送即自动部署：
   ```bash
   git add -A && git commit -m "更新xxx" && git push
   ```
4. 等 1~2 分钟，GitHub Actions 自动构建部署，线上更新。

> 核心：**改完 `git push` 就行，无需手动 build**。GitHub Actions（`.github/workflows/deploy.yml`）自动完成构建 + 部署。

## 3. 自定义域名 —— ⏳ 待处理

当前访问地址：`https://xeldow.github.io/au-docs/`

可选方案：

| 方式 | 效果 | 成本 |
|---|---|---|
| 换 URL 路径 | 仓库改名 `xeldow.github.io` → 访问变 `xeldow.github.io`（无后缀）；或改仓库名换路径 | 免费，但要改 `config.ts` 的 `base` |
| 绑自定义域名 | 用自有域名如 `docs.anotheru.com` | 需自备域名（约几十元/年） |

**自定义域名操作步骤**（待有域名后执行）：

1. GitHub 仓库 Settings → Pages → "Custom domain" 填入域名。
2. 到域名服务商（阿里云/腾讯云等）加 DNS 记录：
   - 子域名（如 `docs.xxx.com`）→ 加 `CNAME` 记录指向 `xeldow.github.io`
   - 裸域名（如 `xxx.com`）→ 加 `A` 记录指向 GitHub Pages 的 4 个 IP（185.199.108/109/110/111.153）
3. 在仓库根加 `CNAME` 文件（内容为域名），并把 `config.ts` 的 `base` 改回 `/`。
4. 等 DNS 生效，勾选 "Enforce HTTPS"。
