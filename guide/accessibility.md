# 辅助功能（无障碍服务）

AnotherU 的核心功能依赖系统的「无障碍服务」权限。由于各手机品牌对无障碍权限的管理方式不同，本文按品牌整理了开启路径和注意事项。

> 如果 AnotherU 提示「无障碍服务未开启」或功能异常，请按以下步骤检查。

---

## 通用步骤

1. 打开手机**设置**
2. 找到**无障碍**（不同品牌入口不同，见下方）
3. 在已安装的服务列表中找到 **AnotherU**
4. 开启开关

::: tip
部分品牌需要额外解除「受限设置」才能开启无障碍权限，详见下方各品牌指引。
:::

---

## 华为（HarmonyOS 4+）

### 开启路径

**设置 → 辅助功能 → 无障碍 → 已安装的服务 → AnotherU → 开启**

### 注意事项

- **受限设置**（HarmonyOS 4+）：若提示「受限设置」，需先解除限制：
  - 设置 → 应用和服务 → 应用管理 → AnotherU → 右上角 ⋮ 菜单 → 允许受限设置（需验证锁屏密码）
- 解除后返回无障碍页面即可正常开启

### 开启路径

**设置 → 辅助功能 → 无障碍 → 已安装的服务 → AnotherU → 开启**

### 注意事项

## 小米 / 红米（HyperOS / 澎湃 OS）

### 开启路径

**设置 → 更多设置 → 无障碍 → 已下载的应用 → AnotherU → 开启**

### 解除受限设置（重要）

HyperOS 对非应用商店安装的 App 会限制无障碍权限，需要手动解除：

1. 先尝试在无障碍列表中点击 AnotherU 的开关（会触发受限提示）
2. 返回设置 → 应用设置 → 应用管理 → 找到 AnotherU
3. 点击右上角 ⋮ 菜单 → **允许受限设置**
4. 验证锁屏密码后，返回无障碍页面重新开启

::: warning
如果应用详情页右上角没有「允许受限设置」选项，说明你还没触发过受限弹窗。请先去无障碍页面点一下开关触发弹窗，再回来操作。
:::

## OPPO / 一加（ColorOS 13+）

### 开启路径

**设置 → 其他设置 → 无障碍 → 已安装的服务 → AnotherU → 开启**

### 注意事项

- ColorOS 13+ 开启时可能要求输入锁屏密码确认
- **受限设置**解除：设置 → 应用 → 应用管理 → AnotherU → 右上角 ⋮ → 允许受限设置
- 若权限被系统自动回收，可在应用管理中关闭「权限自动回收」

## vivo / iQOO（OriginOS 4+）

### 开启路径

**设置 → 快捷与辅助 → 无障碍 → 已安装的服务 → AnotherU → 开启**

### 注意事项

- 部分机型路径为：设置 → 更多设置 → 无障碍
- 开启时可能弹出安全提示，点击「仍然开启」即可
- 若服务频繁被系统关闭，需配合保活设置（参见 [保活设置](./keep-alive)）

## 常见问题

### 无障碍服务开启后又自动关闭了？

这通常是系统省电策略导致的。请配合 [保活设置](./keep-alive) 中的步骤，确保 AnotherU 不被后台清理。

### 列表中找不到 AnotherU？

1. 确认 App 已从正规渠道安装（非第三方传输）
2. 重启手机后再查看
3. 部分品牌需要在「应用管理」中手动授权

### 开启后弹窗提示「受限设置」？

这是 Android 13+ 的安全策略。按上方各品牌的步骤解除限制即可——核心操作是在**应用详情页右上角菜单**中选择「允许受限设置」。
