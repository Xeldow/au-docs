# 辅助功能（无障碍服务）

AnotherU 的核心功能依赖系统的「无障碍服务」权限。由于各手机品牌对无障碍权限的管理方式不同，本文按品牌整理了开启路径和注意事项。

> 如果 AnotherU 提示「无障碍服务未开启」或功能异常，请按以下步骤检查。

---

## 通用步骤

1. 打开手机**设置**
2. 找到**无障碍**（或「辅助功能」）
3. 在已安装的服务列表中找到 **AnotherU**
4. 开启开关

::: tip
部分品牌需要额外关闭「受限设置」或手动解锁无障碍权限，详见下方各品牌指引。
:::

---

## 华为 / 荣耀（HarmonyOS / EMUI）

### 开启路径

**设置 → 辅助功能 → 无障碍 → 已安装的服务 → AnotherU → 开启**

### 注意事项

- **受限设置**：HarmonyOS 3.0+ 可能提示「受限设置」，需要在应用详情页手动解除限制：
  - 设置 → 应用和服务 → 应用管理 → AnotherU → 右上角菜单 → 解除受限设置
- 部分荣耀机型路径为：设置 → 辅助功能 → 无障碍 → 更多已下载的服务

## 小米 / 红米（MIUI / HyperOS）

### 开启路径

**设置 → 更多设置 → 无障碍 → 已下载的应用 → AnotherU → 开启**

### 注意事项

- MIUI 14 / HyperOS 新增了「安全限制」，首次开启无障碍时可能弹窗拦截，需按提示连续点击允许
- 如果列表中找不到 AnotherU，尝试：设置 → 应用设置 → 应用管理 → AnotherU → 权限 → 检查是否有无障碍相关选项
- HyperOS 部分版本路径变为：设置 → 辅助功能 → 无障碍

## OPPO / 一加（ColorOS）

### 开启路径

**设置 → 系统设置 → 无障碍 → 已下载的应用 → AnotherU → 开启**

### 注意事项

- ColorOS 13+ 对无障碍权限加强管控，可能要求输入锁屏密码确认
- 如遇「为了安全，此设置暂不可用」提示，需先到开发者选项中关闭「禁止权限监控」（开发者选项入口：设置 → 关于手机 → 连续点击版本号 7 次）

## vivo / iQOO（OriginOS / Funtouch OS）

### 开启路径

**设置 → 系统管理 → 无障碍 → 已下载的服务 → AnotherU → 开启**

### 注意事项

- OriginOS 3+ 路径可能为：设置 → 更多设置 → 无障碍
- vivo 部分机型会在开启无障碍后弹出安全提示，点击「仍然开启」即可
- 若服务频繁被系统关闭，需配合保活设置（参见 [保活设置](./keep-alive)）

## 常见问题

### 无障碍服务开启后又自动关闭了？

这通常是系统省电策略导致的。请配合 [保活设置](./keep-alive) 中的步骤，确保 AnotherU 不被后台清理。

### 列表中找不到 AnotherU？

1. 确认 App 已从正规渠道安装（非第三方传输）
2. 重启手机后再查看
3. 部分品牌需要在「应用管理」中手动授权

### 开启后弹窗提示「受限设置」？

这是 Android 13+ 的安全策略。按上方各品牌「注意事项」中的步骤解除限制即可。
