# 保活设置

Anotheru 需要在后台持续运行才能正常工作。但国产手机的省电策略通常会自动清理后台应用，导致功能失效。本文按品牌整理了防止被清理的设置方法。

> 如果你发现 Anotheru 的触摸条、面板、单指模式等功能在锁屏后失效，请按以下步骤设置。

---

## 通用原则

保活需要做好三件事：

1. **允许自启动** — 让 App 能在开机或被关闭后自动恢复
2. **关闭电池优化** — 不让系统限制后台活动
3. **锁定后台** — 在最近任务列表中锁住，防止被一键清理

---

## 华为（HarmonyOS 4+）

### 1. 允许自启动

**设置 → 应用和服务 → 应用启动管理 → 找到 Anotheru → 关闭「自动管理」→ 手动开启「允许自启动」「允许关联启动」「允许后台活动」**

### 2. 关闭电池优化

**设置 → 应用和服务 → 权限管理 → 右上角菜单 → 特殊访问权限 → 电池优化 → 选择「所有应用」→ 找到 Anotheru → 设置为「不允许」**

### 3. 锁定后台

从底部上划打开最近任务 → 找到 Anotheru 卡片 → **下拉卡片锁定**（出现🔒图标）

### 额外建议

- 设置 → 电池 → 更多电池设置 → 开启「休眠时始终保持网络连接」
- 关闭省电模式和超级省电模式

## 荣耀（MagicOS 7.0+）

### 1. 允许自启动

**设置 → 应用 → 应用启动管理 → 找到 Anotheru → 关闭「自动管理」→ 手动开启「允许自启动」「允许关联启动」「允许后台活动」**

### 2. 关闭电池优化

**设置 → 应用 → 权限管理 → 特殊访问权限 → 电池优化 → 所有应用 → Anotheru → 不允许**

### 3. 锁定后台

从底部上划打开最近任务 → 找到 Anotheru 卡片 → **下拉卡片**（右上角出现🔒图标）

### 额外建议

- 设置 → 电池 → 开启「性能模式」可进一步减少杀后台
- 关闭省电模式

## 小米 / 红米（HyperOS / 澎湃 OS）

### 1. 允许自启动

**设置 → 应用设置 → 应用管理 → Anotheru → 自启动 → 开启**

### 2. 关闭电池优化

**设置 → 电池 → 找到 Anotheru → 省电策略选择「无限制」**

### 3. 锁定后台

从底部上划打开最近任务 → 长按 Anotheru 卡片 → 点击**锁定**（🔒）

### 额外建议

- 确保以下权限已开启：设置 → 应用设置 → 应用管理 → Anotheru → 权限管理 → 开启「后台弹出界面」「显示悬浮窗」「锁屏显示」
- 关闭省电模式和超级省电模式

## OPPO / 一加（ColorOS 13+）

### 1. 允许自启动 + 后台运行

**设置 → 应用 → 应用管理 → Anotheru → 耗电管理 → 允许完全后台行为、允许自启动、允许关联启动**

### 2. 关闭省电

**设置 → 电池 → 关闭省电模式 / 超级省电模式**

### 3. 锁定后台

从底部上划打开最近任务 → 点击 Anotheru 卡片上方 ⋮ → 点击**锁定**

## vivo / iQOO（OriginOS 4+）

### 1. 允许自启动

**设置 → 应用 → 权限管理 → Anotheru → 所有权限 → 开启「自启动」「关联启动」「后台弹出界面」「锁屏显示」**

### 2. 允许后台高耗电

**设置 → 电池 → 后台耗电管理 → Anotheru → 允许后台高耗电**

### 3. 锁定后台

从底部上划打开最近任务 → 点击 Anotheru 卡片名称旁的箭头 → 选择**锁定**（出现🔒图标）

### 额外建议

- 关闭省电模式、超级省电和睡眠模式
- 长按 Anotheru 图标 → 应用详情 → 确保「暂停闲置应用的活动」为关闭状态

## 设置完成后验证

1. 完成上述设置后，**重启手机**
2. 等待 1~2 分钟，检查 Anotheru 是否自动启动
3. 打开 Anotheru，确认触摸条等功能正常
4. 锁屏等待 10 分钟后解锁，再次检查功能是否仍然正常

::: tip
如果设置后仍有问题，可能是系统更新重置了权限。建议每次系统更新后重新检查以上设置。
:::
