# 保活设置

AnotherU 需要在后台持续运行才能正常工作。但国产手机的省电策略通常会自动清理后台应用，导致功能失效。本文按品牌整理了防止被清理的设置方法。

> 如果你发现 AnotherU 的触摸条、面板、单指模式等功能在锁屏后失效，请按以下步骤设置。

---

## 通用原则

保活需要做好三件事：

1. **允许自启动** — 让 App 能在开机或被关闭后自动恢复
2. **关闭电池优化** — 不让系统限制后台活动
3. **锁定后台** — 在最近任务列表中锁住，防止被一键清理

---

## 华为 / 荣耀（HarmonyOS / EMUI）

### 1. 允许自启动

**设置 → 应用和服务 → 应用启动管理 → 找到 AnotherU → 关闭「自动管理」→ 手动打开「允许自启动」「允许关联启动」「允许后台活动」**

### 2. 关闭电池优化

**设置 → 电池 → 更多电池设置 → 关闭「休眠时始终保持网络连接」之外的省电项**

或：设置 → 应用和服务 → 应用管理 → AnotherU → 电池 → 选择「不限制」

### 3. 锁定后台

从底部上划打开最近任务 → 找到 AnotherU 卡片 → **下拉卡片锁定**（出现锁图标）

## 小米 / 红米（MIUI / HyperOS）

### 1. 允许自启动

**设置 → 应用设置 → 应用管理 → AnotherU → 自启动 → 开启**

或：设置 → 更多设置 → 自启动管理 → 找到 AnotherU 开启

### 2. 关闭电池优化

**设置 → 电池 → AnotherU → 选择「无限制」**

或：设置 → 应用设置 → 应用管理 → AnotherU → 省电策略 → 无限制

### 3. 锁定后台

从底部上划打开最近任务 → 长按 AnotherU 卡片 → 点击**锁定**（🔒）

### 额外建议

- MIUI / HyperOS 的「内存扩展」功能建议开启（设置 → 更多设置 → 内存扩展）
- 关闭「场景化省电」：设置 → 电池 → 更多电池设置 → 关闭

## OPPO / 一加（ColorOS）

### 1. 允许自启动

**设置 → 应用管理 → 应用列表 → AnotherU → 自启动 → 允许**

### 2. 关闭电池优化

**设置 → 电池 → 更多设置 → 优化所有应用的电池使用 → 找到 AnotherU → 选择「不优化」**

或：设置 → 应用管理 → AnotherU → 耗电管理 → 允许后台运行 + 允许关联启动

### 3. 锁定后台

从底部上划打开最近任务 → 长按 AnotherU 卡片 → 点击**锁定**

### 额外建议

- ColorOS 13+ 新增「智能限制后台」，需在电池设置中关闭
- 一加机型路径基本一致（ColorOS 内核）

## vivo / iQOO（OriginOS / Funtouch OS）

### 1. 允许自启动

**设置 → 应用与权限 → 自启动管理 → 找到 AnotherU → 开启**

### 2. 关闭电池优化

**设置 → 电池 → 后台高耗电 → 允许 AnotherU**

或：设置 → 应用与权限 → 应用管理 → AnotherU → 电池 → 允许高耗电

### 3. 锁定后台

从底部上划打开最近任务 → 向下拖动 AnotherU 卡片 → 出现🔒图标即锁定成功

### 额外建议

- OriginOS 3+ 有「应用行为记录」，确保 AnotherU 不在限制名单中
- 如仍被清理，可尝试：设置 → 系统管理 → 开发者选项 → 关闭「后台进程限制」

## 设置完成后验证

1. 完成上述设置后，**重启手机**
2. 等待 1~2 分钟，检查 AnotherU 是否自动启动
3. 打开 AnotherU，确认触摸条等功能正常
4. 锁屏等待 10 分钟后解锁，再次检查功能是否仍然正常

::: tip
如果设置后仍有问题，可能是系统更新重置了权限。建议每次系统更新后重新检查以上设置。
:::
