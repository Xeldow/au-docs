# 单指模式

单指模式让你在屏幕左右两侧的区域用**单手滑动**完成常用操作，不用够到屏幕另一端，适合大屏手机单手使用。

## 怎么用

1. 在设置里开启**单指模式**。
2. 在屏幕**左侧或右侧的区域**滑动手指，即可触发绑定的操作。
3. 左右两侧可分别绑定不同的操作。

## 能做什么

- **左右区域独立**：屏幕左边、右边可以各自设置一套操作。
- **侧滑触发**：在区域内滑动执行绑定的快捷操作。
- **点击执行**：在区域内点击执行操作。
