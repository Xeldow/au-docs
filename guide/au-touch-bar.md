# Au 触摸条

Au 触摸条是屏幕边缘的快捷操作面板：在屏幕边缘的触发区域上滑动，即可唤出面板；点击面板里的操作项，一步完成常用操作（截图、返回、扫码、控制音乐等）。

## 怎么唤出面板

1. 在屏幕边缘的**触发区域**上滑动手指，面板即弹出。
2. 点击面板中的操作项执行对应功能。
3. 松手或点击空白处，面板收起。

> 如果滑动经常误触，可在设置里改用**点按模式**（见下方「防误触」）。

## 面板能放哪些操作

面板里的操作项可自由添加、排列。常用的有：

- **系统操作**：通知栏 / 锁屏 / 多任务 / 截图 / 返回 / 回到桌面 / 电源菜单 / 快捷设置 / 闪光灯 / 静音 / 音量加减 / WiFi 开关
- **扫码支付**：微信扫码 / 支付宝扫码 / 支付宝付款码
- **音乐控制**：上一首 / 下一首 / 播放暂停
- **Au 功能**：VPN 影子开关 / 数据备份

## 自定义设置

| 设置项 | 作用 |
|---|---|
| 面板 Grid 配置 | 操作项的排列、添加，长按可拖动排序 |
| 一行展示数量 | 调整面板每行显示几个操作项 |
| 上滑 / 下滑操作 | 给上滑、下滑手势绑定快捷操作 |
| 触发区域 | 调整触发区的位置 / 宽度 / 高度 / 边距（曲面屏防误触） |
| 触摸区域透明度 | 调整触发区的视觉透明度 |
| 点按模式 | 部分机型防误触影响滑动时，改用点按唤出 |
| 恢复默认设置 | 重置触发区域相关参数 |

## 关于会员

面板操作项的**数量对免费用户有限制**（免费最多 2 个），开通会员可添加更多。详见会员说明。
