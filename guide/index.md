# 使用说明

AnotherU 各功能的使用说明。功能上线一个，这里补一份。

## 功能列表

- [登录与注册](./login) — 手机号验证码/密码登录，首次登录自动注册。
- [Au 触摸条](./au-touch-bar) — 屏幕边缘滑出快捷面板，一键执行常用操作。
- [Au 面板设置](./panel-settings) — 调整触摸条面板的外观、触发方式和布局。
- [Au 面板操作项](./panel-items) — 面板里可配置的快捷操作一览。
- [单指模式](./one-hand-mode) — 屏幕左右两侧单手滑动/点击执行操作，适合大屏单手使用。
- [数据备份与恢复](./backup) — 导出/导入配置数据，支持本地与微信备份，换机一键恢复。
- [权限管理](./permissions) — 统一管理 App 所需的各项系统权限。

> 更多说明书陆续补充中。
